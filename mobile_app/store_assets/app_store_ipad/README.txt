App Store Connect — iPad 12.9" / 13" screenshots (portrait)

Apple accepts either size for the "iPad 12.9 or 13 inch" slot:

  2048x2732_portrait  → 2048 × 2732 px
  2064x2752_portrait  → 2064 × 2752 px

Upload one set (or both if Media Manager lists both). Connect often accepts one.

Source: same iPhone previews as store_assets/app_store_iphone (470×1024), scaled + center-cropped
to iPad aspect ratio. For a universal app, Apple prefers real iPad Simulator captures (iPad Pro 12.9"
or 13") at Window → Physical Size, then ⌘S — replace these files when you have them.

Format: files must be real PNG or JPG (App Store rejects .png files that are JPEG data). These were
re-encoded with: sips -s format png

Files: 01_login … 07_profile (same order as iPhone folder).
