# User Instruction Note (Arabic)

شايف كل هاد الحكي بدي تحطو ب اكثر من ملف قسمهم ب كيفك المهم عشان بدي تمشي على هاد الحكي بزبط ومن دون نقصان.  
وبس تخلص تقسيمهم لملفات عشان تمشي عليهم ويكونو مرجع الك، بدي تشوف شو عدد ملفات الباك اند وعدد ملفات الفرونت اند الخاص بموقع الويب وعدد الملفات الموجودة بالموبايل ابب.  
عشان بعديها احكيلك كيف بدك تشتغل على الامر الي اعطيتك اياه وطلبت منك تقسمو لملفات ويكون مرجع الك.  
والمهم عندي كل الي بعتلك اياه بدي يتنفذ بالحرف الواحد.
